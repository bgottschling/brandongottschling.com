> **Why**  
> One home for research notes, projects, and writing—lightweight, fast, and easy to grow. It’s a “living workshop” for shipping in public.

## Stack Overview

- **Stack:** Next.js 15 (App Router), MDX + filesystem content, Tailwind, shadcn/ui, `remark-gfm`, `rehype-slug`/`autolink-headings`, Vercel.  
- **Design:** warm, minimal UI; high-contrast cards; animated **BackgroundNetworkStable** canvas with “harmony” moments.

---

## What changed in v0.3

**Reading-first layout**
- New **centered reading column** (max-w-3xl) with a **glass “column-blur” scrim** behind it: only the left/right edges softly fade so text remains crisp.
- Background network moved under a controlled stacking context (bg `-z-30` → scrim `z-0` → content `z-10`).

**Filters & navigation (shared pattern)**
- Replaced horizontal chip bar with a **left sidebar grid** of **descriptive tiles** (labels + one-line blurbs + counts).  
- Added **mobile Filters sheet** (hamburger): same grid, opens from the left, updates URL params.
- Sticky, compact **Search + View** bar (search input + grid/list toggle) lives above results.

**Blog**
- Sidebar facet = **Categories** (Faith, Life, Fitness, Relationships, Work, Technology, Travel, Economics, Civics, Other).  
- Rebuilt index to use **descriptive grid** + counts; high-contrast **FancyCard** for results (title hover-underline only).  
- Moved page `themeColor` to **`export const viewport`** (fixes Next warning).  
- Fixed RSC boundary issues by making the sidebar a **Client Component** that handles URL updates itself.

**Research**
- New index with sidebar facet **Area**: *Macro & Markets, Technology & Tools, Unity/Game, Design & UX, Faith & Philosophy, Other*.  
- Tag-based area inference; same search/view controls; shared item renderer.

**Projects**
- New index with sidebar facet **Stage**: *Idea, Prototype, Beta, Live, Archived*.  
- Stage inferred from `status`/tags; same search/view controls.

**Content pipeline & safety rails**
- **`primaryCategory`** now required for blog posts; if omitted, a logger **infers** from tags and warns during build.  
- Fixed `searchParams` usage in pages to **await** the Promise (Next 15 requirement).  
- `mdx-components` wired up safely (no RSC leakage); CTA mapping corrected.

**Accessibility & polish**
- Larger click targets, clear focus states, better color contrast.  
- No default underline on card links; underline appears on title hover for clarity.  
- Keyboard-friendly Filters sheet and sidebar buttons.

## Highlights (implementation notes)

**New / updated components**
- `src/components/EdgeScrim.tsx` – glass **column-blur** variant using `backdrop-filter` + linear mask (left/right fades).  
- `src/components/layouts/CenteredFilterShell.tsx` – three-column shell: **[left gutter / centered content / right gutter]**; sidebar sits away from the reading lane.  
- `src/components/SidebarCategoryGrid.tsx` – descriptive **grid tiles** in the sidebar (Client Component, self-navigating).  
- `src/components/MobileFilterSheet.tsx` – mobile drawer that reuses the same grid and closes on pick.  
- `src/components/SearchViewBar.tsx` – sticky search input + grid/list toggle.  
- `src/components/FancyCard.tsx` – higher contrast, subtle lift on hover, no full-card underline.  
- `src/components/ItemsGridList.tsx` – shared renderer for grid/list views.

**Facet config / inference**
- `src/lib/buckets.ts` – blog categories (labels, descriptions, tag map, inference).  
- `src/lib/research-facets.ts` – **Area** constants, labels/descriptions, tag-based inference.  
- `src/lib/projects-facets.ts` – **Stage** constants, labels/descriptions, inference from `status`/tags.

**Pages**
- `src/app/(site)/blog/page.tsx` – rebuilt with sidebar grid + counts, SearchViewBar, and centered results.  
- `src/app/(site)/research/page.tsx` – new page using **Area** facet.  
- `src/app/(site)/projects/page.tsx` – new page using **Stage** facet.

**Layout / background**
- `src/app/layout.tsx` – wraps site in `relative isolate`; pins **BackgroundNetworkStable** to `-z-30`, scrim to `z-0`, header/main/footer to `z-10+`.

**Next.js correctness**
- Moved per-page `themeColor` to `export const viewport`.  
- Resolved RSC errors by avoiding server→client function/ReactNode props; icons are chosen by **string keys** on the client.

## Developer notes

- **No tooltips needed:** Descriptions are visible; the grid tiles animate subtly on hover/active.  
- **Performance:** The blur is **column-masked** (not full-screen). Animations are CSS-only; no Framer dependency.  
- **Extensibility:** Add new facets by editing the facet libs and passing options to the sidebar; results pages don’t change.
